# SigmaOS-packages

Package-manager core for SigmaOS: dependency resolution, installation, and
verification.

## Development

```bash
make build
make test
```

Package transactions must be deterministic, verifiable, and recoverable. Record
format, trust, rollback, and compatibility changes in the pull request. See the
central [SigmaOS repository](https://github.com/AaryanSinghChauhan09/SigmaOS)
for ecosystem status.
